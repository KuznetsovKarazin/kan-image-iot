KAN Person Detection Model Analysis Summary

- Total parameters: 586,272
- Trainable parameters: 582,872

- Feature dimension: 32
- KAN hidden dimensions: [24, 16]
- KAN grid points: 5

Performance Metrics:

- ROC AUC: 0.953
- Person detection precision: 0.900
- Person detection recall: 0.857

Inference Performance:
- Single image inference: 52.68 ms
- Batch inference (16 images): 3.82 ms per image
- Batch inference (32 images): 1.97 ms per image

Test Dataset:
- Test dataset size: 6000
- Test dataset classes: ['no_person', 'person']

The model is suitable for IoT deployment with excellent balance of accuracy,
size and speed. The 2.24 MB model size allows 
deployment on memory-constrained devices while maintaining good detection performance.
