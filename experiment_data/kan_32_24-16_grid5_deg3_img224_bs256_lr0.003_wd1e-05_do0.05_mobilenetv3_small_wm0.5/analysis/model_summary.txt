KAN Person Detection Model Analysis Summary
=====================================================

Model Characteristics:
- Model size: 1.09 MB
- Total parameters: 285,584
- Trainable parameters: 282,184
- Image size: 224x224
- Feature dimension: 32
- KAN hidden dimensions: [24, 16]
- KAN grid points: 5
- KAN spline degree: 3

Performance Metrics:
- Test accuracy: 86.77%
- ROC AUC: 0.945
- Person detection precision: 0.894
- Person detection recall: 0.834

Inference Performance:
- Single image inference: 51.87 ms
- Batch inference (16 images): 3.75 ms per image
- Batch inference (32 images): 1.92 ms per image

Test Dataset:
- Test dataset size: 6000
- Test dataset classes: ['no_person', 'person']

The model is suitable for IoT deployment with excellent balance of accuracy,
size and speed. The 1.09 MB model size allows 
deployment on memory-constrained devices while maintaining good detection performance.
